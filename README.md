A one-image world atlas of Thursday 26 November 2026: a hand-drawn world map on a deep-navy atlas background pins the day's seven biggest stories by region — North Korea's tactical nuclear push, Ukraine's strike on a Russian air base, new US tariffs, a second US court blocking the birthright citizenship order, Pakistan's first astronaut flying on China's Shenzhou-24, the deadly Cairo tanker fire, and BepiColombo's arrival at Mercury — with a numbered headline strip below the map so a picture editor can read the whole day at a glance.

## Run it

```sh
python3 main.py
```

This writes `entry.png` (1024x1024, deterministic) to `/output/entry.png` and to the repository root. No network is used.
